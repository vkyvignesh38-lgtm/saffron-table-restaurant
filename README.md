# Saffron Table — Restaurant Website Demo

A premium, responsive South Indian restaurant website created as a freelance portfolio demonstration.

## Overview

Saffron Table is a fictional restaurant website designed to demonstrate modern frontend development, responsive UI/UX, interactive components, and clean project organization.

## Features

- Responsive multi-page website
- Premium restaurant UI
- Dynamic menu filtering
- Food gallery with lightbox
- Reservation form validation
- Mobile navigation
- Call and WhatsApp CTAs
- Google Maps integration
- Responsive mobile design
- SEO-ready structure
- Accessibility considerations
- Photo credits and legal pages

## Pages

- Home
- About
- Menu
- Gallery
- Reservation
- Contact
- Legal / Photo Credits

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Python
- Pillow
- Git & GitHub
